Fake News Detection System

A Machine Learning based web application that helps identify whether a news article is Real or Fake using Natural Language Processing (NLP) and classification techniques.

📌 Overview

Fake news spreads rapidly across digital platforms and can create misinformation among people. This project aims to detect fake news articles by analyzing textual content using machine learning models.

The system allows users to enter news content and receive prediction results instantly through a simple and user-friendly interface.

---

🚀 Features

- Fake news prediction using Machine Learning
- Clean and user-friendly interface
- Real-time news analysis
- Text preprocessing and classification
- Fast prediction results

⚙️ Installation

1️⃣ Clone the repository

git clone https://github.com/ommabhishek/fake-news-detection-system.git

2️⃣ Navigate to the project directory

cd fake-news-detection-system

3️⃣ Install dependencies

pip install -r requirements.txt

4️⃣ Run the application

python app.py

---

▶️ Usage

1. Open the application in your browser.
2. Enter or paste a news article/content.
3. Click on the predict button.
4. The system will classify the news as Real or Fake.
